**Minecraft · Fabric · DeepSeek API · ИИ-жители**
Проект на паузе (06.08.2026), направление развития меняется (см. конец).

## ЧАСТЬ 1. МАСТЕР-КОНЦЕПЦИЯ

**Концепция:** Полноценная мультиагентная симуляция человеческого социума внутри Minecraft с использованием мультимодальных LLM (текст + зрение), обладающих физической агентурностью, памятью и динамическими потребностями.

### 1. Архитектура Личности (Геном) и Память
Нейросеть не просто генерирует текст, она отыгрывает математически заданный профиль. При спавне житель формирует свой «Геном» (каждый стат 0–100), определяющий все решения.

**Психологический профиль (15+ статов):**
- Мораль — склонность к преступлениям, воровству или доносам
- Эмпатия — помощь другим (альтруизм) и романтическая привязанность
- Упрямство (характер) — спорить/доказывать правоту или поддаться толпе (стадный инстинкт)
- Агрессия — шанс применить насилие вместо слов
- Трудолюбие — генерация расписания (работать или гулять)
- Жадность — цены в торге и желание воровать
- Экстраверсия — частота инициации диалогов (сам подходит)
- Смелость — реакция на угрозы (сражаться/убегать)
- Любопытство — подойти и проанализировать действия игрока (скриншот)
- Интеллект — сложность речи и интриги (ложные обвинения)
- (+ общительность, паранойя, склонность к сплетням, нарциссизм)

**Динамические Потребности (двигатель ИИ):**
Голод, Сон/усталость, Социализация, Финансы. Нехватка денег при высокой жадности и низкой морали → решение ограбить сундук.

**Трёхуровневая память:**
- **RAM:** текущие задачи, планы на часы, недавние мысли
- **Долгосрочная (социальный граф):** отношение к UUID игроков/NPC, поступки (кто сломал дом, кто помог), романтика (Entity ID)
- **Когнитивная инерция:** жёсткий запрет в промпте на лёгкую смену долгосрочной памяти. Чтобы переубедить упрямца — нужны доказательства или взятка

### 2. Восприятие Мира (Сенсоры и Зрение)
- **Мультимодальность (Глаза ИИ):** Vision API (DeepSeek), житель получает скриншот того, куда смотрит
- **Тайминги зрения:** при начале диалога (через 1 сек), каждые 5 запросов к API (экономия), при реактивных событиях, или по команде игрока/соседа «Посмотри на это!»
- **Формат «УВИДЕННОЕ»:** сухой контекст → ИИ решает сам
  - `[УВИДЕННОЕ: Удар. Агрессор: Игрок. Жертва: Боб]` → если Боб друг → зовёт Голема; враг → радуется
  - `[УВИДЕННОЕ: Игрок ломает Блок(Бревно)]` → чекает Любопытство → подходит: «Зачем ты это делаешь?»

### 3. Конструктор Действий (Action API)
LLM возвращает JSON с массивом actions → житель комбинирует как конструктор:
- `statement(target, fact, intent)` — общение (сообщить/обвинить/соврать/флиртовать/угрожать)
- `interact_block(action, x,y,z, intent)` — ломать/ставить/использовать
- `interact_entity(action, target, intent)` — ударить/передать предмет/поцеловать
- `manage_inventory(action, item)` — экипировать/выбросить/спрятать
- `move(state, target, speed)` — навигация (follow/убегать/патрулировать/красться)
- `investigate(coords)` — пойти на звук/событие + скриншот
- `express(emotion)` — анимации (кивок/паника/смех/частицы)
- `change_stance(posture)` — сесть/лечь/встать
- `memory_update(...)` — переписывание своей базы знаний
- `schedule_update(...)` — обновление планов

### 4. Социальная Симуляция и Экономика
- **Стадный инстинкт и сплетни:** жители обмениваются инфой; слабохарактерные переписывают память под давлением толпы; упрямые спорят
- **Динамическое расписание (цепные реакции):** сломанное рабочее место → свободное время → падают финансы → голод → милостыня или воровство
- **Живая экономика и бартер:** торговля в приватном чате, скидки словами, успех от репутации + гена Жадности; безвозмездная помощь (альтруизм), если житель любит
- **Интриги:** ИИ сам ломает блок, замечает игрока, делает скриншот, обвиняет игрока ради выгоды/репутации

### 5. Инфраструктура, Отладка, Настройки
- Интеграция с VillagerNames и UUID (защита от смены ников)
- Мощный сетевой клиент (переход на официальный платный DeepSeek API, избегание 429)
- GUI настроек (ModMenu): тайминги, кулдауны, API-ключи
- Тотальное логирование в /debug
- Система команд `/mind [тип] [действие] [цель] [значение]`:
  - **Read (re):** `re me/st/sc/in` — память/гены/расписание/инвентарь
  - **Change (ch):** `ch st "Bob" "iq:150"`, `ch me "Bob" "clear"` (амнезия)
  - **Force (fo):** кукловод — `fo na "Bob" "x y z"`, `fo ac "Bob" "interact_block(...)"`

## ЧАСТЬ 2. ЧТО ЕСТЬ СЕЙЧАС (текущее состояние)

### Суть
Мод превращает ванильных жителей в разумных AI-агентов с характером, памятью, эмоциями, диалогами через DeepSeek API. Жители видят игрока, реагируют, подбирают предметы, едят, помнят историю.

### Архитектура (файлы)
| Компонент | Файл | Роль |
|---|---|---|
| Ядро | `Notaloneanymore.java` | Инициализатор, сенсоры |
| AI-движок | `VillagerMixin.java` (~1300 стр / 86K строк) | Геном, 5 типов памяти, навигация, авто-мысли |
| Чат | `ServerChatMixin.java` | Диалог игрока с жителем |
| Интерфейс | `DialogAgent.java` | 20+ методов |
| Регионы | `RegionManager.java` / `ZoneDetector.java` | HOME/WORK/VILLAGE/CUSTOM/WILD |
| Команды | `MindCommand.java` | `/mind` |
| Конфиг | `ModConfig.java` | JSON: ключ, модель, температура, регионы |
| Имена | `VillagerNamesBridge.java` | 230K+ имён, 166K+ фамилий |
| Сенсоры | `ExplosionMixin.java`, `BlockPlaceMixin.java` | Взрывы, размещение блоков |

### Личность (8+3 параметра)
aggression, extraversion, curiosity, bravery, moral (+ дрейф ±30 от окружения)
Мировоззрение: individualism, traditionalism, materialism.
Когнитивная усталость (+2/запрос, −30/ночь сном).

### Память — 5 типов
RAM, долгосрочная (вес 1–5), диалоговая, мысли (кольцевой буфер 10), социальный граф (relation −100…+100, seenCount, lastSeenTick, tag: friend/enemy/vandal/customer/stranger).

### Сенсоры (события → реакция, кулдаун 15 сек)
Разрушение блоков (фильтр по зонам), взрывы, урон по жителю, смерть рядом, игрок рядом (только Java+соцграф, без LLM).

### Физические действия (без нейронки)
pиckupNearbyItems (3 блока), autoEat (голод>40), dropRandomItem, навигация (follow/flee/go/wander/work/home).

### Регионы
HOME (12×12×12 по кровати), WORK (8×8×8), VILLAGE (авто-слияние), CUSTOM (/mind region add), WILD. Подсветка: зелёный/синий/жёлтый/фиолетовый.

### Окружение в промпте
Время суток+яркость+небо, сезон, погода, биом, snapshot окружения (15 блоков), инвентарь, потребности, память, соцграф.

### Контекст-кэш (экономия)
systemPrompt (~800 токенов, статичный → cache hit) + userPrompt (~200, динамика → cache miss). Экономия ~80%.

### Режимы и команды
`/mind lang`, `/mind compliance`, `/mind` (состояние), `/mind re st/me/sc/in/hi`, `/mind ch st/me`, `/mind fo na`, `/mind debug on/off`, `/mind debug boxes`, `/mind region`, `/mind config`, `/mind spawn_test`.

## ЧАСТЬ 3. НОВЫЕ ИДЕИ (от Clouд)

### 🧠 Психология и личность
1. **Травмы и триггеры** — психологическая травма от события (удар молнии → паника при грозе; убил друга → агрессия при виде игрока). Теги в долгосрочной памяти, влияют на решения.
2. **Когнитивные искажения по геному** — параноик интерпретирует нейтральное как угрозу («он следит за мной»), нарцисс любой разговор о себе считает восхищением. Фильтр восприятия в промпте, а не поведение.
3. **Эго и самооценка (отд. параметр)** — публичное унижение снижает, похвала повышает. Низкая самооценка + агрессия = депрессивная агрессия; низкая + эмпатия = альтруизм-компенсация.
4. **Мировоззрение как ось** — индивидуализм↔коллективизм, традиционализм↔прогрессивизм, материализм↔идеализм. Оценивают поступки других.
5. **Усталость от решений** — чем больше LLM-запросов за день, тем импульсивнее, хуже память, чаще соглашается. Восстанавливается сном.

### 👥 Социальная динамика
6. **Репутационные слои** — личная / публичная / профессиональная. Ложь в торговле → падает проф., но не личная. Героизм → публичная, но конкретный житель может ненавидеть.
7. **Социальные роли и иерархия** — стихийно: лидер, козёл отпущения, отшельник, сплетник. Вычисляются из взаимодействий, влияют на доверие при конфликте.
8. **Конфликты и примирения (дуга)** — напряжение → инцидент → открытый конфликт → игнор/примирение/эскалация. Другие встают на сторону.
9. **Коллективная память деревни («легенда»)** — событие, увиденное 3+ жителями, становится «фактом деревни»; новые жители знают историю с рождения (игрок = герой или злодей).
10. **Семьи и династии** — родство по UUID/совместной истории; смерть родственника = тяжёлая травма; дети наследуют геном с мутациями («чёрная овца»).

### 🌍 Мир и среда
11. **Сезонная психология** — зима: тревога, агрессия в торге, замкнутость; лето: диалоги, расширение дома, романтика (веса в промпте).
12. **Территориальная память** — список `{pos, emotion, memory_text}`; «у этого дерева познакомился с Бобом», «в этом подвале страшно». Триггер мысли при навигации.
13. **Слухи с затуханием** — информация распространяется по графу с искажением (LLM «пересказывает» с учётом генома: параноик преувеличит, эмпат смягчит).

### 💡 Механики и геймплей
14. **Ложь как стратегия** — высокий интеллект + низкая мораль = лгает (ложная инфа о ресурсах, ложное обвинение). Внутреннее напряжение, если эмпатия не нулевая.
15. **Экономические кризисы** — у большинства finance<20 одновременно → кризис: цены вверх, альтруизм вниз, преступность, «банды» из агрессивных/аморальных. Выход — игрок вливает ресурсы / чинит рабочие места.
16. **Амбиции и долгосрочные цели** — 1–2 «жизненные амбиции» при спавне (дом побольше, стать главным торговцем, найти пару, выучить рецепты). Достиг → всплеск счастья + новая.
17. **Сны и подсознание** — раз в ночь LLM генерирует «сон» по событиям с высоким весом. Перерабатывает травму или усиливает страх. «Плохой сон» → раздражительность на день.
18. **Мораль динамическая, не константа** — дрейфует от среды (моралисты рядом → рост; кризис/насилие → падение). «Моральная коррупция/рост».

### 💪 Полный контроль физики
Житель сможет: **ломать блоки как игрок** (и получать выпавшее), **ставить блоки** (строить постройки / делать то, что просит игрок за деньги), **имитировать профессию** (делать инструменты, собирать урожай, чистить), плюс **приватное окно торговли**.

## ЧАСТЬ 4. ИДЕИ НАДИ (голосовое, 18.08.2026 01:35) — ВАЖНО ⭐

1. **Приватный чат с жителем** (live-диалог, другие игроки не слышат):
   - В чате можно **ТОРГОВАТЬСЯ**: выставлять цены, житель оценивает по своим потребностям
   - Приватная торговля = экономика деревни, движок = потребности жителя

2. **Потребности — двигатель экономики**: каждый житель сам пополняет потребности (голод/усталость/социалка/финансы) → живая экономика деревни.

3. **Архитектура — как Hermes Agent, НЕ OpenClaw**: агент сам создаёт и улучшает свои **СКИЛЛЫ** (не задачи). Житель = агент, развивающий навыки сам.
